# 🏓 Ping Pong Game

A simple and interactive Ping Pong game built with HTML, CSS, and JavaScript.

This project was created to practice JavaScript game logic, keyboard controls, animations, collision detection, and DOM manipulation while recreating a classic arcade-style experience.

---

## ✨ Features

- 🏓 Classic Ping Pong gameplay
- 🎮 Keyboard paddle controls
- 🤖 Ball movement and collision detection
- 🧠 Score tracking system
- ⚡ Real-time gameplay updates
- 🎨 Clean and responsive interface
- 📱 Optimized for desktop and modern browsers

## 🎮 Controls

### Player Controls

| Key | Action |
|------|--------|
| `W` | Move paddle up |
| `S` | Move paddle down |

_You can customize controls inside the JavaScript file._

---

## 🧠 Game Mechanics

- The ball bounces off paddles and walls
- Players score when the opponent misses the ball
- The game updates scores automatically
- Speed and direction change dynamically during gameplay
